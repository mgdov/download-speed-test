# Download Speed Test

Консольный скрипт на Python для измерения скорости скачивания с заданного HTTP(S)-адреса. Без сторонних зависимостей.

## Запуск

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/mgdov/download-speed-test.git
cd download-speed-test
python3 speed_test.py "https://example.com/large-image.jpg"
```

Замените пример на настоящий URL доступного файла, желательно достаточно большого для замера. Скрипт скачает его **10 раз**, поэтому учитывайте трафик и ограничения сервера.

```bash
python3 speed_test.py "https://example.com/large-image.jpg" --timeout 15
python3 speed_test.py --help
```

`--timeout` — ограничение ожидания отдельной блокирующей сетевой операции, по умолчанию 30 секунд. Это не общий лимит длительности теста.

## Что измеряется

Каждый запрос начинается только после полного чтения и закрытия предыдущего ответа. Данные читаются блоками по 64 KiB и не сохраняются на диск. Объём считается по фактически прочитанным байтам тела ответа, а не по заголовку `Content-Length`.

Время измеряется монотонным `time.perf_counter_ns()`: от начала открытия соединения до полного чтения и закрытия ответа. Оно включает установку соединения, ожидание сервера, редиректы и скачивание. Итог — скорость загрузки **с конкретного сервера**, а не гарантированная пропускная способность интернет-канала.

Для 10 успешных запросов:

```text
Среднее время = сумма времени запросов / 10
Скорость MB/s = сумма байтов / сумма секунд / 1 000 000
Скорость Mbit/s = сумма байтов × 8 / сумма секунд / 1 000 000
```

Единицы десятичные: **1 MB = 1 000 000 байт**, **1 Mbit = 1 000 000 бит**, **1 байт = 8 бит**. Среднее время выводится в секундах. Для итоговой скорости используется отношение общего объёма к общему времени, а не среднее арифметическое скоростей отдельных запросов.

Пример формата вывода (условные данные):

```text
Completed requests: 10
Total downloaded: 10000000 bytes (10.000 MB)
Total request time: 2.000000 s
Average request time: 0.200000 s
Download speed: 5.000 MB/s
Download speed: 40.000 Mbit/s
```

## Ошибки и ограничения

- Поддерживаются HTTP и HTTPS; редиректы обрабатывает стандартная библиотека Python.
- При сетевой ошибке, таймауте, HTTP-ошибке или обнаруженном обрыве ответа скрипт останавливается с кодом 1, указывает номер запроса и не печатает успешный итог по неполным данным. Повторных попыток нет: они изменили бы требуемое число запросов.
- Некорректные аргументы дают код 2, успешное выполнение — 0.
- Запрашивается несжатый ответ (`Accept-Encoding: identity`), но если сервер игнорирует заголовок, учитываются полученные байты тела, включая сжатое представление. Заголовки HTTP и сетевые накладные расходы в объём не входят.
- `Cache-Control: no-cache` просит проверить актуальность ответа; поведение кеша сервера/CDN полностью не контролируется.
- Отдельного прогрева и параллельных запросов нет. Небольшие файлы сильнее отражают задержку соединения и сервера.

## Проверка

```bash
python3 -m unittest -v
```

Тесты поднимают локальный HTTP-сервер и не используют интернет. Проверяются 10 полных последовательных загрузок, точный объём, HTTP-ошибка, обрыв ответа, формулы скорости и некорректные аргументы.

## Возможные улучшения

Добавить общий дедлайн теста, статистику отдельных запросов и медиану/p95, вывод JSON/CSV и сравнение нескольких серверов. Расширить тесты на таймауты, редиректы и ответы без `Content-Length`. Сохранить режим ровно 10 последовательных запросов как основной.
