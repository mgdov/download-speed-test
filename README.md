# Замер скорости скачивания

Небольшой консольный скрипт на **TypeScript для Node.js 22+**. Принимает URL файла, скачивает его 10 раз по очереди и выводит среднее время, общий объём и скорость.

## Запуск

Нужны Node.js 22+ и npm.

```bash
git clone https://github.com/mgdov/download-speed-test.git
cd download-speed-test
npm ci
npm run build
npm start -- "https://example.com/large-file.jpg"
```

Замените пример настоящим HTTP(S)-адресом файла. Параметр только один — URL. Файл скачивается **10 раз**: учитывайте размер и расход трафика.

## Как работает код

Вся программа находится в `download.ts`, в одной функции `main`:

1. Берёт адрес из `process.argv[2]` и проверяет протокол.
2. Создаёт два счётчика: `totalBytes` и `totalSeconds`.
3. В цикле делает 10 запросов. `await` внутри `for` обеспечивает последовательность.
4. Проверяет HTTP-статус. Ответ 404 или 503 считается ошибкой.
5. Читает **всё тело** каждого ответа через `for await`. Каждый блок добавляет свой `byteLength` к объёму. Файл не накапливается целиком в памяти и не сохраняется на диск.
6. Прибавляет длительность полного запроса к общему времени. `performance.now()` измеряет монотонное время в миллисекундах, деление на 1000 переводит его в секунды.
7. Считает и печатает результат. Если произошла ошибка, выводит сообщение в stderr и завершается с кодом 1. Успех — код 0.

`await fetch()` сам по себе не означает, что файл уже скачан: нужно дочитать `response.body`. Поэтому замер заканчивается после цикла чтения тела.

## Формулы и единицы

- Среднее время в секундах = суммарное время / 10.
- Скорость в **MB/s** = все байты / все секунды / 1 000 000.
- Скорость в **Mbit/s** = скорость в MB/s × 8.

Здесь **1 MB = 1 000 000 байт**, **1 Mbit = 1 000 000 бит**. Например, 10 000 000 байт за 2 секунды — это 5 MB/s или 40 Mbit/s.

Мы делим общий объём на общее время, а не усредняем скорости отдельных запросов.

## Пример вывода

Условные значения для объяснения формата:

```text
Запросов: 10
Скачано: 10000000 байт
Общее время: 2.000000 с
Среднее время: 0.200000 с
Скорость: 5.000 MB/s
Скорость: 40.000 Mbit/s
```

## Ограничения

- Это скорость получения данных с выбранного сервера, а не точный замер максимальной скорости провайдера. Время включает ожидание сервера, соединение, редиректы и чтение тела; соединение может переиспользоваться.
- Таймаут каждого полного запроса фиксирован: **30 секунд**, включая чтение тела. `AbortSignal.timeout(30_000)` отменяет слишком долгую операцию. Настройки `--timeout` в этой упрощённой версии нет.
- Объём считается по телу, которое выдаёт fetch. Заголовки HTTP и транспортные расходы не учитываются. Заголовок `Accept-Encoding: identity` просит несжатый ответ; если сервер его игнорирует, fetch может декодировать ответ, и объём будет отражать декодированные данные.
- `Cache-Control: no-cache` просит проверить актуальность ответа, но не гарантирует отсутствие серверного кеша.
- Fetch следует редиректам: 10 загрузок могут включать больше 10 HTTP-переходов.
- При ошибке программа прекращает замер, не делает повторных попыток и не выдаёт успешную скорость по неполным данным.

Добавить автоматические тесты на последовательность загрузок, расчёты, ошибки и таймауты, а при реальной потребности — поштучную статистику и JSON-вывод. Основной режим оставить простым: один URL и 10 последовательных загрузок.
